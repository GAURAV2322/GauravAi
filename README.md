# GauravAI — AI-Powered Portfolio Assistant

An AI-powered portfolio website featuring a chatbot that answers questions about my education, technical skills, and projects.

This project was built to explore LLM API integration, web development, and my first experience deploying a web application.

## 🚀 Live Demo

https://gauravai.onrender.com/

## ✨ Features

- Interactive AI chatbot for portfolio-related questions
- Dark, futuristic user interface
- Integration with the Groq API
- Conversation history during a chat session
- Responsive web interface

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **AI:** Groq API
- **Frontend:** HTML, CSS, JavaScript
- **Libraries:** python-dotenv
- **Deployment:** Render
- **Version Control:** Git and GitHub

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/GAURAV2322/GauravAi.git
cd GauravAi
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure environment variables

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key
FLASK_SECRET_KEY=your_secret_key
```

Replace the placeholder values with your own credentials. Never commit your `.env` file or expose your API key publicly.

### 4. Start the application

```bash
python app.py
```

Open http://127.0.0.1:5000/ in your browser.
